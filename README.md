# 🛒 ListMercadão

Aplicação web para controle de listas de compras e gerenciamento de tarefas, desenvolvida em HTML, CSS e JavaScript puro.

🔗 **Acesse online:**  
https://SEU-USUARIO.github.io/listmercadao/

---

## 🚀 Funcionalidades

### Mercado
- Criar múltiplas listas
- Adicionar produtos com quantidade e valor
- Controle de saldo
- Estatísticas em tempo real
- Exportar lista
- Compartilhar via WhatsApp

### Tarefas
- Gerenciador estilo Kanban
- Progresso por tarefa
- Drag and drop
- Salvamento automático no navegador

---

## 🛠️ Tecnologias
- HTML5
- CSS3 responsivo
- JavaScript (localStorage)

---

## 📱 Compatibilidade
- Desktop
- Mobile
- Funciona offline
